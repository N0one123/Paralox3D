Object and Entity

Entity is an alias for Object. Objects are the main 3D scene entities and provide transforms, appearance, hierarchy, collision, components, lookup identity, and lifecycle control.

Object(model="cube", position=(0,0,0), rotation=(0,0,0), scale=(1,1,1), name=None, engine=None, scene=None, parent=None, color=None, opacity=1.0, texture=None, enabled=True, visible=True)
PropertyDescription
idUnique numeric identifier assigned by the engine.
objectPreferred object identifier. The variable name is used when it can be detected, otherwise the object's name is used.
modelModel or primitive name. The current native renderer provides a cube primitive.
namePrimary user-facing object name.
position, x, y, zWorld-space position and individual coordinates. Position values are Vec3-compatible.
rotationWorld rotation as a Vec3, using x/pitch, y/yaw, z/roll style angles.
scaleWorld scale as a Vec3. A scalar scale value is expanded to all three axes.
local_position, local_rotation, local_scaleTransform values relative to the object's parent.
forward, right, upNormalized direction vectors derived from the object's rotation.
parent, childrenParent-child hierarchy. children is a tuple.
componentsTuple containing attached components.
colliderThe object's Collider. It becomes unavailable after destroy().
colorRGB tuple in the 0..1 range.
opacityObject opacity value in the 0..1 range.
textureStored texture value for the object's visual state.
visibleControls whether the object is visible to the renderer.
enabledControls active object state. Disabled objects do not receive component updates and are excluded from collision queries.
tagsSet of string tags.
persistentMarks an object to survive scene clearing and scene serialization rules.

Raycasts and spatial queries

raycast(origin, direction, distance=1000, ignore=())

Cast a ray through the engine's enabled AABB colliders. origin may be an Object, an owned Object.position, a Vec3, or a 3-tuple. If the origin belongs to an Object, that object is automatically ignored. The nearest hit is returned as a RaycastHit; otherwise None.

RaycastHit memberDescription
objectThe hit object's preferred .object identifier.
entityThe actual hit Object instance.
pointWorld-space hit point.
normalApproximate surface normal of the hit AABB face.
distanceDistance from the ray origin to the hit.
boxcast(center, size, direction, distance=1, ignore=())

Cast an axis-aligned box-shaped query along a direction. Returns the nearest RaycastHit or None.

spherecast(center, radius, direction, distance=1, ignore=())

Convenience cast using a box with dimensions radius * 2 on each axis. Returns the nearest RaycastHit or None.

overlap_box(center, size, ignore=())

Return a list of enabled collidable objects whose AABBs overlap the requested box.

overlap_sphere(center, radius, ignore=())

Return a list of enabled collidable objects overlapping the sphere query.

Developer visualization: with modes.developer = True, a raycast is drawn as a temporary developer line for about 0.3 seconds. A newer raycast from the same origin Object replaces the previous line.

bind("jump", "space")
if action_pressed("jump"):
    player.y += 1

if held("w", "shift"):
    player.move_forward(8 * dt)

Frame delta time

dt

Global frame delta time. It represents the elapsed seconds since the previous frame. Because dt is a mutable numeric proxy, importing it directly remains safe:

from paralox3d import dt

def update():
    player.x += speed * dt

Import style

from paralox3d import *

The public package exports the documented engine, scene, entity, math, collision, input, camera, component, timing, mode, error, lookup, and named-color APIs. The reference above describes the public surface intended for game code; private implementation modules and internal engine helpers are not part of this reference.
