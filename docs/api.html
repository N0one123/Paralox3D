Object and Entity

Entity is an alias for Object. Objects are the main 3D scene entities and provide transforms, appearance, hierarchy, collision, components, lookup identity, and lifecycle control.

Object(model="cube", position=(0,0,0), rotation=(0,0,0), scale=(1,1,1), name=None, engine=None, scene=None, parent=None, color=None, opacity=1.0, texture=None, enabled=True, visible=True)

Properties

id : Unique numeric identifier assigned by the engine.

object : Preferred object identifier. The variable name is used when it can be detected, otherwise the object's name is used.

model : Model or primitive name. The current native renderer provides a cube primitive.

name : Primary user-facing object name.

position, x, y, z : World-space position and individual coordinates. Position values are Vec3-compatible.

rotation : World rotation as a Vec3, using x/pitch, y/yaw, z/roll style angles.

scale : World scale as a Vec3. A scalar scale value is expanded to all three axes.

local_position, local_rotation, local_scale : Transform values relative to the object's parent.

forward, right, up : Normalized direction vectors derived from the object's rotation.

parent, children : Parent-child hierarchy. children is a tuple.

components : Tuple containing attached components.

collider : The object's Collider. It becomes unavailable after destroy().

color : RGB tuple in the 0..1 range.

opacity : Object opacity value in the 0..1 range.

texture : Stored texture value for the object's visual state.

visible : Controls whether the object is visible to the renderer.

enabled : Controls active object state. Disabled objects do not receive component updates and are excluded from collision queries.

tags : Set of string tags.

persistent : Marks an object to survive scene clearing and scene serialization rules.

Methods

Methods

enable() : Enable the object and return the object.

disable() : Disable the object and return the object.

set_parent(parent) : Set or replace the parent and recompute world transforms. Returns the object.

detach() : Remove the parent. Returns the object.

add_tag(tag) : Add a string tag and return the object.

remove_tag(tag) : Remove a tag and return the object.

has_tag(tag) : Return True if the object has the tag.

move(x=0,y=0,z=0) : Translate the object. Alias of translate(). Returns the object.

translate(x=0,y=0,z=0) : Change local position and recompute hierarchy. Returns the object.

rotate(x=0,y=0,z=0) : Change local rotation. Returns the object.

scale_by(x=1,y=None,z=None) : Multiply local scale. Missing y/z values use x. Returns the object.

look_at(target) : Rotate toward an Object or position-like target. Returns the object.

distance_to(target) : Return distance to an Object or position-like target.

move_forward(distance) : Move along forward. Returns the object.

move_right(distance) : Move along right. Returns the object.

move_up(distance) : Move along up. Returns the object.

add(component) : Attach a component, set its owner, call on_start(), and return the component.

get(component_type) : Return the first attached component matching the supplied type, or None.

remove(component) : Remove a component, call on_destroy(), and clear its owner.

destroy() : Permanently destroy the object, its children and component state, remove it from the engine, and remove its native entity.

Position ownership: an object's position retains its owning object. Therefore both raycast(origin=player, ...) and raycast(origin=player.position, ...) can identify the same origin object. The origin object is automatically ignored by the raycast.

Examples

player = Object(position=(0, 1, 0), color=blue)
player.position = (0, 2, 0)
player.rotation.y += 45
player.disable()
player.enable()
player.destroy()

Engine and startup

Engine(title="Paralox3D", width=1280, height=720, max_fps=0)

title, width, height, max_fps : Engine configuration values.

start(update=None) : Run the engine loop. An optional callable is used as the per-frame update callback.

run() : Compatibility alias that starts the engine.

close() : Destroy the native engine and stop the loop.

start()

The zero-boilerplate public startup function. It finds an update() function in the caller's module and runs the default engine.

get_default_engine()

Return the current default Engine, creating one when necessary.

Examples

player = Object()
start()
def update():
    player.x += 5 * dt

start()
engine = Engine(title="My Game", width=1280, height=720)
engine.start()

Vec3

Vec3(x=0.0, y=0.0, z=0.0)

The public 3D vector type. It supports iteration and arithmetic and is accepted anywhere a vector-like 3-tuple is documented.

x, y, z : Vector components.

as_tuple() : Return (x, y, z).

copy() : Return a copy, retaining position ownership when present.

length() : Euclidean vector length.

length_squared() : Squared length without a square root.

normalized() : Return a unit vector, or zero vector for zero input.

dot(other) : Dot product.

cross(other) : Cross product.

distance_to(other) : Distance between vectors.

lerp(other,t) : Linear interpolation from this vector to other.

Supported operators include +, -, unary -, scalar *, scalar /, and equality.

Examples

position = Vec3(1, 2, 3)
direction = Vec3(0, 0, 1).normalized()
distance = player.position.distance_to(target.position)

Collider and Collision

Collider(owner, size=None, offset=(0,0,0), enabled=True, is_trigger=False, layer="default", collides_with=None)

Properties

owner : Object owning the collider.

size : AABB dimensions. If not explicitly supplied, the initial object scale is used.

offset : Position offset from the owner.

position : Owner position plus collider offset.

min, max : World-space AABB bounds.

enabled : Whether the collider participates in queries and collision processing.

is_trigger : Marks the collider as a trigger. Collision compatibility checks still use the collider's enabled state.

layer : String collision layer.

collides_with : Set of layers this collider accepts. "*" matches all layers.

sync_to_scale() : Refresh an automatically sized collider from the owner's scale.

Collision(a, b=None)

With two objects, returns a boolean overlap result. With one object, returns a list of other overlapping objects. Invalid or destroyed objects raise a clear error.

Examples

if Collision(player, wall):
    print("Blocked")
hits = Collision(player)
for obj in hits:
    print(obj.object)
player.collider.size = (1, 2, 1)

Raycasts and spatial queries

raycast(origin, direction, distance=1000, ignore=())

Cast a ray through the engine's enabled AABB colliders. origin may be an Object, an owned Object.position, a Vec3, or a 3-tuple. If the origin belongs to an Object, that object is automatically ignored. The nearest hit is returned as a RaycastHit; otherwise None.

object : The hit object's preferred .object identifier.

entity : The actual hit Object instance.

point : World-space hit point.

normal : Approximate surface normal of the hit AABB face.

distance : Distance from the ray origin to the hit.

boxcast(center, size, direction, distance=1, ignore=())

Cast an axis-aligned box-shaped query along a direction. Returns the nearest RaycastHit or None.

spherecast(center, radius, direction, distance=1, ignore=())

Convenience cast using a box with dimensions radius * 2 on each axis. Returns the nearest RaycastHit or None.

overlap_box(center, size, ignore=())

Return a list of enabled collidable objects whose AABBs overlap the requested box.

overlap_sphere(center, radius, ignore=())

Return a list of enabled collidable objects overlapping the sphere query.

Developer visualization: with modes.developer = True, a raycast is drawn as a temporary developer line for about 0.3 seconds. A newer raycast from the same origin Object replaces the previous line.

Examples

hit = raycast(player, player.forward, distance=10)
if hit:
    print(hit.object)
hit = raycast(player.position, player.forward, distance=10)
if hit:
    print(hit.entity)
nearby = overlap_box(player.position, (4, 2, 4))

Keyboard input

key(key_name) : Compatibility shorthand for held().

held(*keys) : True when all supplied keys are held.

any_held(*keys) : True when at least one supplied key is held.

pressed(key) : True for the frame in which a key was pressed.

bind(action, *keys) : Bind a named action to one or more keys. Returns the action name.

action(name) : True while all keys bound to the named action are held.

action_pressed(name) : True when any key bound to the named action is newly pressed.

Built-in key names include letters, digits, space, enter, escape, tab, backspace, shift, ctrl, alt, left, up, right, and down.

bind("jump", "space")
if action_pressed("jump"):
    player.y += 1

if held("w", "shift"):
    player.move_forward(8 * dt)

Examples

if held("w"):
    player.move_forward(5 * dt)
if pressed("space"):
    player.y += 1
bind("jump", "space")
if action_pressed("jump"):
    player.y += 1

Mouse

mouse is the global Mouse instance.

Properties / Methods

position : Current 2D mouse position as (x, y).

x, y : Current mouse coordinates.

dx, dy : Per-frame movement delta.

wheel : Per-frame wheel movement.

left, right, middle : Current held state of each mouse button.

pressed(button) : True during the frame the specified button was pressed.

visible : Controls the public cursor visibility state.

locked : Controls relative mouse mode.

lock() : Enable relative mouse mode.

unlock() : Disable relative mouse mode.

Examples

if mouse.left:
    print(mouse.position)
player.rotation.y += mouse.dx
camera.z += mouse.wheel

Camera

camera is the global Camera instance.

Properties / Methods

x, y, z : Camera position coordinates.

position : Camera position as a Vec3.

pitch, yaw, roll : Camera orientation angles.

look_at(target) : Orient the camera toward a position-like target.

Set modes.camera = True to enable the built-in native camera controls. The camera can be used without creating a Controller.

Examples

camera.position = (0, 5, -10)
camera.look_at(player)
modes.camera = True

Components

Component

Component(owner=None)

owner : Object the component is attached to.

enabled : Enable/disable component updates. Changing it calls the corresponding lifecycle hook.

on_start() : Called when attached through Object.add().

on_enable() : Called when transitioning to enabled.

on_disable() : Called when transitioning to disabled.

update() : Per-frame component callback.

on_destroy() : Called when the component is removed or its owner is destroyed.

Script

Script(owner=None, update=None) is a Component that calls its supplied update callable every frame.

Examples

class Spinner(Component):
    def update(self):
        self.owner.rotation.y += 90 * dt

player.add(Spinner())
script = Script(update=lambda: player.move_forward(dt))
player.add(script)
player.disable()
# Attached components stop updating.

Controllers

ControllerComponent

ControllerComponent(owner=None, height=2.0, speed=5.0, gravity=1.0, jump_height=2.0, jump_duration=0.5, fall_after=0.35, step_height=0.5, sprint=False, sprint_speed=None, sprint_key="shift", jump_speed=None)

Built-in character movement controller with WASD movement, gravity, jumping, stepping, sprinting, and ground checks.

Properties

height : Controller body height.

speed : Normal movement speed.

gravity : Gravity strength multiplier.

jump_height : Default jump height used to calculate jump speed.

jump_duration : Stored jump duration setting.

fall_after : Stored falling delay setting.

step_height : Maximum step height attempted by the controller.

sprint : Whether sprinting is enabled.

sprint_speed : Speed used while sprinting.

sprint_key : Key used for sprinting.

jump_speed : Optional direct jump velocity override.

grounded, jumping, air_time, velocity_y : Runtime movement state.

CharacterController

Compatibility name for ControllerComponent.

Controller

Controller(model="cube", position=(0,1,0), rotation=(0,0,0), scale=(1,2,1), name="Player", engine=None, scene=None, parent=None, color=None, opacity=None, size=None, **kwargs)

Convenience constructor that creates an Object, attaches a ControllerComponent, optionally changes collider size, and returns the ready-to-use Object.

Examples

player = Controller(position=(0, 1, 0))
player.controller.speed = 6
player.controller.sprint = True

Scenes

Scene(name="Scene")

Properties / Methods

name : Scene name.

objects : Objects belonging to the scene.

on_enter, on_exit : Optional lifecycle callbacks.

add(obj) : Add an object and return it.

create(model="cube", **kwargs) : Create an Object belonging to the scene and return it.

enter() : Make the scene current and call on_enter. Returns the scene.

exit() : Call on_exit if supplied.

clear(keep_persistent=True) : Destroy scene objects except persistent objects when requested. Returns the scene.

save(path) : Write scene data as readable JSON and return the resulting Path.

Scene.load(path, on_loaded=None) : Load a JSON scene and return a new Scene.

Scene.switch(scene, on_loaded=None) : Exit the current scene, load if necessary, enter the new scene, and return it.

current_scene()

Return the current Scene, or None when no scene is active.

Examples

scene = Scene("Level 1")
scene.create(position=(0, 0, 0))
scene.enter()
print(current_scene().name)
scene.save("level.json")
loaded = Scene.load("level.json")

Timing

Timer

Timer(duration, callback=None, repeat=False)

Properties / Methods

duration : Timer interval in seconds.

remaining : Remaining time until the next callback.

callback : Callable invoked when the timer expires.

repeat : Whether the timer repeats.

cancelled : Whether the timer has been cancelled.

done : True when a one-shot timer has finished or any timer has been cancelled.

cancel() : Cancel and return the timer.

reset() : Reset remaining time and return the timer.

Functions

after(seconds, callback) → Timer

Schedule a one-shot timer.

every(seconds, callback) → Timer

Schedule a repeating timer.

cancel(timer)

Cancel a timer and remove it from the global timer list.

Examples

after(2, lambda: print("Done"))
timer = every(1, update_score)
timer.cancel()
player.x += speed * dt

Modes

modes is the global runtime mode object.

Properties

modes.developer : Boolean. Enables developer diagnostics, visual collider bounds, and raycast debug lines.

modes.camera : Boolean. Enables the built-in native camera controls.

Both properties require actual booleans. Other values raise TypeError.

Examples

modes.developer = True
modes.camera = True
modes.developer = True
modes.camera = True

Object lookup

Functions

find(name) : Return the first Object whose name matches, or None.

find_all(name) : Return every Object whose name matches.

find_with_tag(tag) : Return every Object containing the supplied tag.

find_by_id(object_id) : Return the Object with the numeric ID, or None.

Examples

player = find("Player")
enemies = find_all("Enemy")
targets = find_with_tag("target")

Error handling

Functions / Types

explain_error(error) : Produce the engine's explanation for an exception.

report_error(error) : Report one exception through the Paralox3D error system.

report_errors(errors) : Report a collection of errors.

ErrorGroup : Public error grouping type used by the error engine.

Developer mode is intended to expose more diagnostic information while the normal mode keeps common engine errors easier to understand.

Examples

try:
    player.destroy()
except Exception as error:
    print(explain_error(error))
try:
    player.color = (1, 2)
except Exception as error:
    report_error(error)
report_errors(errors)

Frame delta time

dt

Global frame delta time. It represents the elapsed seconds since the previous frame. Because dt is a mutable numeric proxy, importing it directly remains safe:

from paralox3d import dt

def update():
    player.x += speed * dt

Examples

def update():
    player.x += speed * dt
move_distance = speed * dt
elapsed += dt

Import style

from paralox3d import *
